## 🔧 Customization Examples

### Change Primary Color
```css
/* In index.css */
.btn-primary {
  @apply bg-gradient-to-r from-blue-500 to-blue-600;
}
```

### Modify Notebook Lines Opacity
```css
body::before {
  opacity: 0.15; /* Change from 0.08-0.12 */
}
```

### Update Typography
```jsx
// In App.tsx
<h1 className="text-5xl font-black">Your Title</h1>
```
