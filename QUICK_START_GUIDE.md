## ✅ Tasks Section

### Adding a New Task
1. Type your task in the input field (it has a cute ✏️ emoji!)
2. Select priority from dropdown
3. Choose a due date
4. Click the **"Add Task"** button

### Task Management
Each task card shows:
- **Title** of your task
- **Due date** displayed below
- **Priority badge** on the right (with warm colors)
- **Edit button** (pencil icon) - modify your task
- **Delete button** (trash icon) - remove your task
- **Checkbox** - mark as complete

### Filtering Your Tasks
- **All** - See every task
- **Active** - Only incomplete tasks
- **Completed** - Only finished tasks

---

## 📅 Calendar Section

### How It Works
1. Click any date to see tasks for that day
2. Use arrow buttons to change months
3. Click **"Today"** to jump to today's date

### Visual Indicators
- **Gradient background** - Your selected date
- **Amber highlight** - Today's date
- **Colored dots** - Task indicators (one per pending task)
  - Red dots = Urgent
  - Orange dots = High
  - Amber dots = Medium
  - Teal dots = Low

### Tasks for Selected Date
Below the calendar, you'll see all tasks for your selected date with the ability to add new tasks for that specific day.

## 🐛 Troubleshooting

### "My data disappeared!"
- Check if you accidentally clicked "Clear All Data"
- Try clearing browser cache and reloading
- Data is saved locally per device

### "The app looks different"
- Clear your browser cache
- Try a different browser
- Check zoom level (should be 100%)

### "Performance is slow"
- Close other browser tabs
- Clear browser history/cache
- Restart browser
